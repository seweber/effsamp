This project uses the `guided-wiki` scaffold (Guided researcher · Markdown wiki); `scaffold check` verifies it.

Read these project files before work as well:
- [`CONTRACT.md`](CONTRACT.md): project-specific contract — rules and base data for this work.
- [`PLAN.md`](PLAN.md): human-owned research overview, goal, approved tasks, and references.
- [`TASKS.md`](TASKS.md): agent proposals for new high-level tasks, discussed with the
  human; accepted proposals are copied into [`PLAN.md`](PLAN.md) by the human.
- [`PROBLEMS.md`](PROBLEMS.md): shared conceptual and structural problems and resolutions.
- [`LOG.md`](LOG.md): terse lab ledger: every experiment, its outcome, and pointers.

Use these scaffold folders for research work:
- `data/`: simulation or experimental output.
- `code/`: independent codebases or helper projects.
- [`wiki/`](wiki/index.md): research wiki for the human, maintained by the agent; start at
  [`wiki/index.md`](wiki/index.md) and [`wiki/overview.md`](wiki/overview.md). Papers live in `wiki/literature/`.
- [`memory/`](memory/index.md): agent working memory; read [`memory/index.md`](memory/index.md) and the current task file.
- `paper/`: final-paper workspace; agent edits only on request.
