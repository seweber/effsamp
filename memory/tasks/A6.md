- Aer Kraus algorithm (source read, copies in scratchpad aersrc/ = qiskit-aer main `statevector_executor.hpp` (sve) and `statevector_state.hpp` (sv)):
  - plain (sv.hpp:1112 `State::apply_kraus`): r uniform; for j < N-1: p_j = qreg.norm(qubits, K_j) (a full read-only reduction pass), stop when accum > r, apply K_j/sqrt(p_j) (read+write pass). Else apply last renormalized.
  - branching (sve.hpp:1672 `Executor::apply_kraus(Branch&)`): norms for j < N-1 until all shots of the branch assigned (usually all N-1), then `branch_shots` → new branches (state copies) each with op K_i/sqrt(p_i) queued.
  - So per damping channel and distinct state: 1 read pass (norm K0) + 1 read/write pass (apply). Two-qubit tensor channel after cp: 4 Kraus ops, up to 3 norm passes.
  - Kraus ops break Aer's gate fusion unless `fusion_allow_kraus` (noisecirc's worker sets it; its fusion failed with heevx on some circuits).
